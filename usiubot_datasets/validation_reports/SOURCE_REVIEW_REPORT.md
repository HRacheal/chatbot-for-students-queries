## How to read this report

* **Safe candidate**: official USIU-Africa source, citable (official URL or handbook page), no open item in the conflict and verification register, and real content. An administrator should still open the page and compare.
* **Needs a decision**: has an open conflict, possibly outdated content, payment details, an unresolved register item, or is an undated Student Handbook section. The register entry is listed; decide with the office concerned.
* **Low value**: a navigation fragment ("Filter By Mode of Study", a heading with no content). Approving it adds noise to search; rejecting or leaving it in draft is recommended.
* **External body**: KUCCPS/CUE/KNQA material; may only ever be cited as external, never as USIU-Africa policy.

## How an administrator approves sources

1. Create the first administrator (once): `.\.venv\Scripts\python.exe -m tools.create_staff --email <email> --name "<name>" --role super_admin` in `backend`.
2. Sign in at `/admin` → **Sources**. Filter by department and status *draft*, or search for the section title.
3. Open each section, compare it with the official page (link shown), then **Approve**, **Reject** or leave as draft. Bulk actions work on the selected rows only.
4. Approval indexes the section at once (BM25 chunks in `source_chunks`); rejecting, archiving or returning it to draft removes it from search at once. Indexes survive restarts (tested).
5. Only super administrators can change source status. Department staff and visitors get 403/401 (tested).

## How to enable live retrieval safely

Live retrieval is off, and should stay off for now:

* The website's robots.txt blocks every crawler not named in it (`User-agent: *` / `Disallow: /`), including `USIUBOT/1.0`. USIUBOT must **not** pretend to be another agent.
* None of the 77 catalogue links has been reviewed.

To turn it on: (1) get the university's web team to add a `User-agent: USIUBOT` allow rule for the public pages, or written permission; (2) run `python -m tools.live_check` and review the catalogue links in the admin dashboard; (3) set `LIVE_RETRIEVAL_ENABLED=true` in `backend/.env` and restart. Live pages are still shown as "fetched from the official website", never as staff-approved.
